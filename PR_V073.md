# PR Title

perf: reduce QuantDesk replay latency without changing research math v0.7.3

# PR Description

## Summary

Performance-focused improvement to QuantDesk v0.7.2. Addresses replay slowdowns and UI unresponsiveness caused by repeated intraday marker scans, repeated Decimal trade binning, obsolete browser requests, and canvas reallocation.

## Changes

- Bounded intraday session/marker index; preserves causal marker ordering and prior-completed-session KDE zones.
- Immutable session-local indexed trade profiles; *same exact* Decimal price bins, POC, VWAP, VAH/VAL and value-area rules.
- Bounded profile response and session caches, invalidated on store reload.
- Separate trade-profile lock so slow archived SIP work does not block replay frames.
- Abort obsolete replay requests, debounce expensive profile fetching while scrubbing, and refresh profile after playback stops.
- Reuse canvas backing store at unchanged dimensions; coalesce hover redraws.
- No broker execution changes, no new runtime dependencies, and no provider/data/license changes.

## Verification

- 120 automated tests passed in development.
- 192 reference/optimized replay frame responses matched exactly.
- Exact indexed/original volume-profile equality across multiple historical cutoffs and bin sizes.
- JS syntax validation passed; browser switching/scrubbing smoke passed through a local API bridge.
- 80,000-trade synthetic benchmark: 8 queries ~267 ms old versus ~75 ms new, including one-time bin index setup (environment-specific, not a guaranteed speedup).

## Limitations

- Cold CSV imports and archival tick decompression still incur I/O cost.
- Fast replay now deliberately postpones tick profiles until playback pauses.
- Validate with actual locally stored market data and Windows browser before merge.
- Research-only; no trading orders, options P&L, or verified alpha.
