# v0.4 — Intraday Research Foundation

Date: November 2026. Research-only incremental upgrade on v0.3.1. No broker/order connection.

- Strict offset-aware 1-minute RTH CSV importer with DST-normalized session validation, duplicate/NaN/price integrity checks, explicit gap and early-close coverage.
- Anchored 5m/15m/1h OHLCV resampling from source 1m bars; no interpolation. All aggregation confined to individual RTH sessions.
- Date + completed-bar replay using daily KDE zones calculated at the previous daily close. The API never sends any later intraday bars or future intraday markers.
- Offline synthetic minute-data generator for a zero-credentials demo (clearly marked synthetic in the UI).
- First-touch descriptive event-study CSV export with future 5,15,30,60-minute underlying price-path observations; no fill/P&L claims.
- Preserved existing v0.3.1 UI palette, daily replay, API and SQLite journal.
- 33 automated tests in the shipped source tree; browser control tests with locally supplied real Python responses passed in the build environment. The browser environment blocked localhost HTTP navigation, so those visual tests were not conducted over a real socket.

**Limits:** Source OHLCV is not order-book liquidity or executed trade-at-price; no options Greeks, live broker, transaction-cost realism, new untouched holdout or validated trading edge.
