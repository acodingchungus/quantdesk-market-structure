# v0.8.1 — Portrait-aware Cross-Market UI

Release type: frontend-only. Builds on v0.8.0.

- Stack research comparison above TradingView watchlists on tall portrait monitors, including portrait desktop viewport widths.
- Replace the fixed 580px watchlist cap with responsive landscape height, natural page scrolling in portrait, and compact one/two/three-column ticker rows.
- Introduce an optional accessible watchlist-focus control that temporarily hides the comparison pane and restores it on demand.
- Prevent status labels and price cells from overflowing narrow cards.
- Keep historical/replay math, cross-asset alignment, provider routing, live data credentials, and the no-order policy exactly as v0.8.0.

Validation: 138/138 local tests, successful JavaScript parse, and five offline Chromium viewport/interaction checks. Real Windows/Opera portrait screen QA remains recommended before merge.
