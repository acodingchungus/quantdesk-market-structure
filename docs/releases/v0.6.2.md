# QuantDesk v0.6.2 — Midnight Graphite + Replay Transport

UI-only polish of QuantDesk v0.6.1.

## Visual design

- Change previous blue-undertone graphite to neutral near-black surfaces (`#030504` app / `#101310` panels / `#090B09` plot).
- Change main active green to a more saturated green (`#22DB58`). Red bearish/error and yellow caution/POC remain distinct.
- Keep self-contained local HTML/CSS/JS, sharp borders, high-contrast labels, mobile layouts and visible keyboard focus.

## Replay

- Improved session and intraday timelines with clear labels and hover/drag previews.
- Live drag-value feedback plus coalesced API requests (85 ms) and a bounded visited-frame cache (22 frames). No prefetch of future candles.
- First/last session and bar, ±5-bar jumps, playback speeds 0.5×/1×/2×/4×.
- Keyboard: arrows, Shift+arrows, Up/Down, Home/End, Shift+Home/End, Space. Editing fields and other workspaces keep their native keyboard input.
- Avoid per-bar notes fetches during intraday replay; notes remain tied to their real symbol/session.

## Verified

- 71/71 Python tests pass when overlaid on the v0.6.1 project.
- Chromium UI smoke tests on 1440 px, 390 px, and 320 px viewports: no JavaScript exceptions or page horizontal overflow.
- Keyboard stepping, Shift+Arrow jumps, session navigation, note-field exclusion, play/pause, slider scrubbing and workspace switches exercised against the local v0.6 API with synthetic demonstration data.

## Unchanged

Research math, daily KDE zones, intraday aggregation, executed-trade profiles, read-only Alpaca streaming, and SQLite storage remain unchanged. Data quality requirements and no-order/no-broker posture remain in force.
