# QuantDesk v0.6 — Market Intelligence Workspaces

- Separated historical replay, opt-in read-only Alpaca live market observation, and daily research diagnostics into three local web workspaces.
- Added point-in-time 5/20-session returns, 20-return realized volatility, SPY/QQQ return correlation, and relative strength for optional sector/leader daily CSVs.
- Added explicit missing/stale-data handling and tests that future-row mutations do not influence a past research snapshot.
- Added an optional WebSocket listener for Alpaca IEX/SIP stock feeds. Off by default; NO order endpoints, no historical mixing, no automatic external connections.
- Added historical daily context downloader and clearly labeled synthetic demo context generator.
- Preserved prior KDE, historical replay, volume-profile, SQLite journal, and localhost-only HTTP server.

See `README_V06.md` for exact installation, data license restrictions, source coverage, mathematical definitions and limitations.
