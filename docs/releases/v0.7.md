# QuantDesk v0.7.0 — Retrospective Quantitative Research

- Daily, causal KDE and prior-day high/low event study with next-session entries.
- Chronological development / validation / retrospective test samples, purging boundary-crossing holds.
- Hypothetical cost sensitivity, descriptive MFE/MAE, monthly-block mean CIs, randomized-direction diagnostic.
- Research Lab graphitical panel and read-only `/api/experiments` endpoint.
- Reproducible CLI JSON/CSV results with source SHA256.
- Git preflight to catch untracked backend modules that broke CI previously.

**Limitations:** no untouched holdout, true walk-forward optimizer, volume-profile/KDE confluence, options execution model, verified trading edge, or order execution. Existing historical periods were examined in past development.
