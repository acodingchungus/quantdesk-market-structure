# QuantDesk v0.6.1 — Graphite Terminal

## Visual-only release

- New high-contrast black/graphite/white UI, with green as primary accent and red/yellow for bearish/errors and POC/cautions.
- Sharper panels, navigation, buttons, form controls, notebook, charts, and volume histogram. Improved small-screen layout and legibility.
- Candlestick canvas now uses graphite tokens for grid, neutral above-price zones, green below-price zones, gray VAH/VAL, and yellow trade-tick POC.
- Live observer explicitly differentiates receiving, stale/no events, disabled, and connection-error states. No additional Alpaca access is requested.
- Research signed 20-session returns are color-coded while unavailable assets stay neutral.
- Existing v0.3.1 theme test updated to reflect new tokens; new v0.6.1 UI regression tests added.

**No change** to Python APIs (backend version stays 0.6), market calculations, historical replay causality, WebSocket ingestion, order safety, SQLite files, or datasets. No new broker execution and no proof of profitability.

## Upgrade

Overlay this patch at the repo root. Do not replace user-edited `README.md`, `LICENSE`, or local data/notes. Run `python -m unittest discover -s tests_market_structure -v` before publishing.
