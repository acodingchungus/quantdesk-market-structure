# v0.5 — Executed-Trade Volume Profile (research prototype)

- Optional strict tick CSV ingestion for executed SPY/QQQ equity trades, not quotes.
- Trade-size-weighted volume-at-price histograms with configurable price bands.
- POC, VWAP, contiguous 70% value area; exploratory HVN/LVN labels.
- Point-in-time replay profile endpoint frozen at the selected completed minute/bar.
- Midnight Navy side panel histogram and optional POC/VA lines on main replay chart.
- Clearly labeled synthetic executed-tick demonstration, no fake profile fallback.
- Historical ticker/CSV provenance SHA-256, regression tests, no broker/order endpoints.
- Optional **read-only** Alpaca historical-trades REST downloader (SIP/IEX, subscription permitting); no real account fetch in tests.

**Not included:** consolidated Level II, quotes, aggressive-side classifications, OPRA, live streaming, provider SDKs, validated trading signals, real tick datasets, and any claim of profitable trading.
