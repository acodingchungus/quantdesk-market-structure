# QuantDesk Market Structure Lab — v0.1

**Status: runnable, read-only research prototype. NOT a trading system; NOT demonstrated alpha.**

A conservative first milestone for the pre-existing Python `quantdesk` project. This add-on **does not replace or modify** the existing QuantDesk accounting, broker, risk, journaling, or kill-switch modules. No options, short-sales, API order submission, credentials in code, or live trading.

## What it does

1. Load point-in-time-ordered, completed **daily** SPY and QQQ OHLCV bars.
2. Find confirmed swing highs/lows; each pivot needs **3 subsequent daily bars**, so it cannot appear early.
3. Approximate the trader's "middle between reaction points" with weighted Gaussian **kernel density estimation (KDE)** over historical pivots. Price extraction uses 70% candle body and 30% wick as a *testable hypothesis*, not established best practice.
4. Convert KDE modes into ATR-scaled candidate **zones**, with at least 2 temporally separated contributing pivots.
5. For each past date, compute candidate zones using **only bars completed before that date**. Save these as a date-stamped level map.
6. After a full daily candle touches a candidate level and closes back on the approach side, hypothetically enter at the **next daily open**, exit on the **third following daily close**. Compare directional signed returns against an equally defined baseline using previous-day highs/lows.
7. Save separate training/holdout summaries and **calendar-month-block bootstrap** confidence intervals (only if sample size is sufficient).

No optimization has been performed in this prototype. Parameters are declared before results, not fitted to the test set.

## Important limitations

- **This is NOT volume profile, order flow, liquidity heatmaps, or options analysis.** OHLCV has one volume figure per bar, not volume at each price, and cannot reveal resting limit orders. Those require appropriately licensed trade-and-quote/depth data and a different analysis module.
- Returns are **underlying ETF directional return proxies** (SPY/QQQ), *not actual strategies or 0–3DTE options P&L*. A fixed 5 bps roundtrip sensitivity deduction is included, but it does not reconstruct spreads, fills, market impact, or option premium dynamics.
- The same day's high/low and close determine a **bar-close signal**; the hypothetical entry is at the next day's open. Never assume a signal was known during the touch bar.
- If prices hit a level intraday but do not reject by the close, the event is ignored. Breakout/retest is not yet modeled.
- Only one event per symbol/source within the cooldown; this removes some dependence, but not all. Multiple levels come from shared history and observations remain correlated.
- A nonrandom set of days triggers each strategy; comparison to previous-day extrema is a **descriptive benchmark, not a randomized causal test**, and sample counts may differ.
- Lookback windows and delayed pivots are causal **given the supplied historical OHLCV**, but retrospectively adjusted data, revised source data, session conventions, and corporate actions mean this is not a fully archived point-in-time vendor dataset.
- SPY and QQQ are highly correlated. Treat them as related opportunities, not independent experiments.
- Holdout date is **2025-12-04** to match the earlier QuantDesk daily-bar research; don't repeatedly tune this prototype on the same holdout and then claim unbiased out-of-sample performance.
- A 180-day lookback plus confirmation reduces usable samples substantially. Empty/uncertain reports are an acceptable scientific outcome.
- No parameter sweep, live alerts, broker connections, order execution, or profitability guarantees.

## Setup (PowerShell on Windows)

Use Python 3.11+ and unpack this folder **anywhere** first:

```powershell
cd "C:\path\to\QuantDesk_Market_Structure_v0_1"
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests_market_structure -v
```

Use **real market data** in `data/SPY.csv` and `data/QQQ.csv` with headers:

```csv
date,open,high,low,close,volume
```

Dates strictly increasing, one completed trading-day row per date. You can use your previously saved Alpaca adjusted daily SPY/QQQ bars by exporting to this format.

### Optional: download adjusted daily bars from Alpaca (read-only)

Install SDK and set **environment variables locally** (never paste keys into chat or commit them):

```powershell
.\.venv\Scripts\python.exe -m pip install alpaca-py
$env:APCA_API_KEY_ID="YOUR_KEY"
$env:APCA_API_SECRET_KEY="YOUR_SECRET"
.\.venv\Scripts\python.exe -m market_structure_lab.fetch_alpaca --start 2024-01-02 --feed iex --output-dir data
```

`iex` only represents one exchange; `sip` is more representative of the consolidated US market but may require a paid subscription. See [Alpaca stock bars docs](https://docs.alpaca.markets/us/reference/stockbars) for details. Downloaders deliberately exclude the current ET date and cannot reconstruct actual historic options fills.

### Run SPY/QQQ research

```powershell
.\.venv\Scripts\python.exe -m market_structure_lab.run --data-dir data --out outputs/market_structure_v01
```

Expected output files:

- `point_in_time_levels.csv`: each day's historical candidate zones, computed the day before.
- `events.csv`: observed reaction events with signal/entry/exit dates, underlying signed return, proxy cost sensitivity.
- `summary.csv`: by symbol, training/holdout, and clustered levels versus prior-day extrema.
- `latest_levels.csv`: recent candidate levels.
- `SPY_latest.png`, `QQQ_latest.png`: latest level overlays on daily closes.
- `experiment_config.json`: recorded experiment settings.

### Smoke test without Alpaca or market data

```powershell
.\.venv\Scripts\python.exe -m market_structure_lab.demo --output-dir data_demo
.\.venv\Scripts\python.exe -m market_structure_lab.run --data-dir data_demo --out outputs/synthetic_demo
```

**Synthetic demo outputs are not real market results.** Do not use the demo to estimate performance.

## Adding to the existing QuantDesk repo

Current installed repo contents weren't provided in this chat, so the existing repo has NOT been changed or inspected. This folder is additive and avoids touching any existing QuantDesk modules.

1. Back up / commit your current QuantDesk state.
2. Copy `market_structure_lab/` and `tests_market_structure/` into your existing repo root (`C:\ai projects\quant_desk` previously).
3. Install `numpy pandas matplotlib` in the existing QuantDesk virtual environment if absent.
4. Run `python -m unittest discover -s tests_market_structure -v` from the existing repo root, then use `python -m market_structure_lab.run ...` on historical CSV files.
5. **Do not merge** this experiment into the existing order/risk engine or switch trading on.
