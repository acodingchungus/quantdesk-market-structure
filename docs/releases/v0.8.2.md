# v0.8.2 — Daily Cross-Asset Signal Research

Research-only confluence study; no new broker or order integration.

- Fixed prior-20-session peer beta/alpha fits, signal-day residuals, historical lead/lag diagnostics and directional confirmation classification for SPY/QQQ using NVDA/SMH/XLK/IWM where synchronized data exists.
- Strict source date matching and no fallback from missing peers to stale prices. Factors never see future closes or unconfirmed intraday data.
- Read-only `/api/cross-signal` and `/api/cross-study` endpoints and a collapsible, responsive study UI in Cross-Market.
- Reuse v0.7 verified clustered KDE events, next-open entry and retrospective chronological partitions; report baseline and confluence subgroups rather than fabricating order fills.
- Existing v0.8.1 portrait layout, original KDE maths and live watchlist providers unchanged.

**Limits:** descriptive study on historically examined periods; no untouched holdout, no trading edge claim, no options P&L. Local daily context may not extend far enough for complete peer coverage.
