# feat: causal cross-asset confluence research v0.8.2

## Summary

Extend QuantDesk's read-only cross-market foundation into a **strictly causal, retrospective** daily signal study. Compare v0.7 KDE price-reaction events against predefined cross-asset confirmation states without changing KDE math, source data, or trade-execution endpoints.

## Changes

- Introduce prior-20-return peer beta/alpha fitting, session-close residual features, historical lead/lag diagnostics, and fixed directional confluence groups.
- Require exact prior-session and signal-date alignment. Missing context peers are unavailable, never forward-filled.
- Reuse the validated v0.7 KDE event study's next-open entries, purge rules, partitions, and adjustable roundtrip cost proxies for subgroup comparisons.
- Add read-only `/api/cross-signal` and `/api/cross-study` APIs.
- Add a collapsible research panel to Cross-Market, preserving the v0.8.1 portrait layout and 66-symbol watchlist.
- Extend CI source imports and tracked-source preflight; update release math documentation.

## Verification

- 147 Python automated tests pass locally (138 existing + 9 new).
- Inline JavaScript parses under Node.
- API test verifies strict no-order endpoints and read-only research responses.
- Historical mutation and missing-session tests verify factors cannot see future closes or invent peer observations.
- Real Windows/Opera GUI and native historical data coverage need local checking before merge.

## Safety and interpretation

- **No order execution, no new Alpaca key handling, no live market data as historical input.**
- Fixed thresholds are exploratory and NOT optimized. Lead/lag correlations do not imply causation.
- All historical partitions have previously been inspected; the final partition is retrospective, not an untouched holdout.
- No validated alpha, options fill claims, or production backtest; small sample sizes and adjusted/raw price issues remain.

**Merge into `main` only after review.**
