# PR description

## QuantDesk v0.7.2 — Multi-Asset Historical Backfill

### Summary

Adds a reproducible, source-aware path to collecting historical minute bars and daily market-intelligence context for a curated universe beyond SPY and QQQ.

### Implementation

- Central curated symbol universe: core ETFs, benchmarks, sector ETFs, Magnificent Seven, semiconductors, and energy.
- Extends the existing read-only Alpaca SIP/IEX archive to those symbols without enabling new broker or order routes.
- Adds explicit `plan`, `download-minutes`, `coverage`, `download-context`, and `publish-core` commands.
- Reuses compressed per-day archives, source metadata, checksums, and safe resumability.
- Adds a local coverage report that clearly distinguishes absent weekdays from verified market closures.
- Preserves existing daily context files, without overwriting private research data.
- Makes newly added context symbols visible to the existing Research Lab market-intelligence view.
- Keeps SPY/QQQ as the only instruments enabled for KDE Replay and v0.7 experiments.

### Testing and safety

- 108 automated tests passed during development; seven new regression tests.
- Enhanced Git source preflight and CI source-import checks.
- No live SIP subscription, no network requests on import, and explicit download authorization.
- No credentials, research archives, trade data, or SQLite files distributed.
- No changes to trading mathematics or order execution.

### Limitations / next steps

Calendar-aware completeness, raw-vs-adjusted price reconciliation, audited trade-condition filters, and statistically tested cross-asset entry features remain future work. Historical data coverage alone does not establish profitable alpha.

**Research-only; no broker orders.**
