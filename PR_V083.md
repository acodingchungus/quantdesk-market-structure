## Overview

Add offline, deterministic v0.8.3 data audits, daily trade/no-trade decisions, cost-aware cash/position research simulation, and reproducible experiments without changing the existing workstation frontend, KDE algorithm, live feed, or order permissions.

### Implementation

- `data_quality_v083.py`: actual XNYS session calendar, missing/extra session detection, source SHA256, explicit raw/adjusted price basis and no silent forward fills.
- `strategy_v083.py`: original KDE/ATR primitives, frozen SPY/QQQ long-only 10%-notional decision policy, v0.8.2 confluence factor, stable decision IDs, next-session eligibility and no-trade rationale.
- `research_pipeline_v083.py`: audited input manifests, two matched portfolio variants (KDE only / KDE plus confirmation), assumed spread/slippage, chronological retrospective split reporting, deterministic reports, and standalone HTML output.
- 15 new unit/regression tests; local suite **162/162**; CI synthetic offline demo/audit/study smoke.
- Repo-source checks updated. User-review manifest is `.gitignore`d; source code and tests contain no Alpaca secrets.

### Explicit boundaries

**This is a research-infrastructure candidate, not a validated strategy.** Real historical data cannot be audited from GitHub. The data audit will intentionally block if the local dataset provenance or price adjustment basis is unknown, or if six assets lack matching complete exchange sessions. All historical evaluation windows were already examined, so there is no untouched holdout. Fills are hypothetical daily OHLC approximations, not NBBO/OPRA or broker execution.

No broker calls, credentials, writable trade endpoints, short positions, options, or claimed alpha. v0.9 must implement separate durable broker execution/risk machinery and independent prospective validation.
