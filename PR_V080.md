# feat: build QuantDesk v0.8 cross-market intelligence and live watchlists

## Summary

Adds a read-only, point-in-time cross-asset research foundation and brings the screenshot TradingView watchlists into QuantDesk without inventing non-stock data feeds.

## Changes

- Captured **66 unique, visibly supplied TradingView symbols** with categorical provider requirements and a CSV transcription for review.
- Added `cross_asset_v08.py`: exact-as-of daily and verified archived 1m alignment, local rolling correlation and target-relative return; rejects missing future, stale or mismatched observations.
- Added `live_watchlist_v08.py`: opt-in, bounded batched Alpaca IEX/SIP stock + separate Alpaca U.S. crypto snapshot polling; 48 stock/ETF and 3 crypto candidates, with explicit unavailable states.
- Expanded approved historical equity universe, fixed explicit-symbol-only backfills, and widened optional priority WebSocket allowlist (maximum 30 symbols).
- Added Cross-Market dashboard workspace and read-only `/api/watchlist`, `/api/cross-asset`, `/api/live/watchlist` endpoints.
- Preserved v0.7 detector, study calculations, historical replay, trade profile, journal and no-order API policy.
- Extended Git preflight and Python 3.11/3.12 CI import checks.

## Known limits

- Indices, continuous futures, USOIL CFD, macro series, and delisted PDCE are visible but **not represented as live equity prices**. Appropriate sources still needed.
- Basic IEX stock observations are not consolidated SIP. Crypto U.S. venue may differ from TradingView prices. No streams start unless explicitly opted in.
- This is a descriptive cross-asset foundation, not a proven strategy, execution simulator, or valid forward-test result.

**Research only. No broker orders and no established trading alpha.**
