## QuantDesk v0.7.1 — Paper Credential Vault + Replay UX

**What changed**
- Added optional Windows Credential Manager credential retrieval for Alpaca **paper trading** keys, with one-time local hidden-prompt setup.
- Kept compatible environment-variable support; rejects partial key pairs rather than mixing credentials.
- Updated historical daily/minute/trade/context/SIP archive fetchers and opt-in read-only live monitoring to use one centralized resolver.
- Improved intraday timeframe switching and the `Last date` button so they land on the latest completed bar directly.
- Added 6×, 8× and 10× replay speeds.
- Added automated tests for credential handling and navigation contracts.

**Validation**
- 101/101 automated tests passed against the assembled v0.7 tree in development.
- Requires a Windows-side smoke test for actual Credential Manager and browser behavior.
- No real Alpaca credentials are in this pull request. No broker order routes, no changes to research mathematics.

**Security scope**
- The encrypted Windows vault entry belongs to the local Windows user, not the repository.
- Local software running with that Windows user's permissions may still access the vault; do not treat it as absolute protection from local agents or malware.
- Research-only / read-only historical downloads and optional read-only live monitoring.
