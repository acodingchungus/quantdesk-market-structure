# ui: adaptive Cross-Market portrait layout and watchlist focus v0.8.1

## Summary

Uses the entire portrait-monitor workspace instead of forcing a wide two-column layout and trapping the 66-symbol watchlist in a 580px scroll box. Presentation-only follow-up to v0.8.0.

## Changes

- Orientation-aware stacked research and watchlist panels for tall portrait screens (including 1080×1920 and 1440×2560), with ordinary page scrolling.
- Adaptive watchlist density: three columns at wide portrait widths, two at medium, one at narrow; compact historical comparison grid.
- Viewport-responsive watchlist panel heights in landscape; existing side-by-side workstation layout retained.
- Focus watchlist / Show comparison toggle with `aria-pressed` that does not touch data or provider polling.
- Smaller-card overflow safeguards and explicit layout regression tests.
- Consistent Cross-Market frontend version label v0.8.1; no Python backend version bump required.

## Testing

- **138/138 Python tests passed** locally (135 previous + 3 layout tests).
- Inline JavaScript parse passed.
- Offline Chromium fixture smoke tested five window sizes: 690×1200, 1080×1920, 1150×2048, 1440×2560, 1920×1080; 66 rows rendered, no horizontal overflow or JavaScript errors, and focus toggle worked.
- **Windows/Opera GX device QA is still required**: offline fixture tests don't confirm real market data or display scaling.

## Safety / scope

No modifications to KDE, statistical research, point-in-time data, SQL journal, credentials, paid market feeds, watchlist routing, or broker/order endpoints. Live observations remain opt-in and read-only. No claims of validated trading alpha.
